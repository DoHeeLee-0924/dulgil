# 둘길 · 이번 주에 뭐 하지?

모눈종이와 스티커로 꾸민 커플 데이트 다이어리입니다.

## 실행

Node.js 22 이상에서 `run.bat`을 실행하거나 아래 명령을 사용하세요.

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

## 현재 화면과 기능

- 표지 → 월간 캘린더 → 날짜별 데이트 기록
- 지난 데이트: 일기, 장소 링크, 사진 최대 6장
- 예정 데이트: 방문 순서대로 장소와 링크, 계획 메모 작성
- 예정 코스를 다녀온 기록으로 전환, 수정 및 삭제
- 추억과 예정 코스 목록, 첨부 사진 표지
- 모바일 반응형, 로컬 손글씨 폰트

기록은 현재 브라우저의 localStorage에 저장됩니다. 기기 간 동기화나 커플 공동 편집은 지원하지 않습니다. 초기 2개 기록은 수정·삭제 가능한 예시입니다. 기존 UI 데이터는 삭제하지 않지만 새 다이어리는 별도 키 `dulgil-diary-v2`를 사용하므로 자동 표시되지 않습니다. 사진은 한 장당 10MB 이하이며 저장 시 긴 변 1000px 이하 JPEG로 축소됩니다. 브라우저 저장 용량 초과 시 저장하지 않고 안내합니다.

## 코드

- `public/index.html`: 다이어리 화면과 SVG 스티커
- `public/style.css`: 모눈종이·파스텔·콜라주 디자인
- `public/app.js`: 캘린더, 기록 및 사진 첨부, 브라우저 저장
- `server.mjs`: 기존 정적 서버와 장소 검색 API

기존 추천·지도·코스 편집 모듈과 `docs/`, `data/`는 후속 통합을 위해 보존했습니다. 현재 다이어리 화면은 해당 모듈 및 검색 API를 호출하지 않습니다. 기존 기능 설계는 `docs/`를 참고하세요.
