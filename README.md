# 둘길 · Dulgil

둘이 갈 길을 정하고, 함께한 순간을 남기다.

커플의 취향·시간·예산을 반영한 데이트 코스 계획 및 추억 기록 서비스입니다.

- [유저플로우](docs/user-flow.md)
- [구현 계획](docs/implementation-plan.md)

## 현재 상태

기획 문서와 구현 제안을 정리한 단계입니다. 실행 가능한 앱 코드는 아직 없습니다. 원본 문서는 내용을 그대로 보존했으며, 변경 제안과 미결정 사항은 구현 계획에서 구분합니다.

## 제안하는 첫 개발 목표

모바일 우선 웹에서 로그인 → 커플 연결 → 조건 입력 → 코스 추천·편집·저장 → 데이트 완료 → 추억 기록의 전체 흐름을 구현합니다. 기술 구성과 외부 서비스는 구현 계획의 제안이며 아직 확정되지 않았습니다.
