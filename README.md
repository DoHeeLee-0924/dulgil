# 둘길 · Dulgil

둘이 갈 길을 정하고, 함께한 순간을 남기다.

## 바로 실행하기

Windows에서는 Node.js 22 이상을 설치한 뒤 프로젝트 폴더의 `run.bat`을 더블클릭하세요. 서버가 준비되면 브라우저가 자동으로 열립니다. 실행 창을 켜둔 채 사용하고, 종료할 때는 Ctrl+C를 누르세요.


Node.js 22 이상이 필요합니다. 외부 패키지 설치나 API 키 없이 실행할 수 있습니다.

```bash
git clone https://github.com/DoHeeLee-0924/dulgil.git
cd dulgil
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

```bash
npm run dev   # 파일 변경 시 서버 재시작
npm test      # 추천 제약·계산·서버 테스트
```

포트 변경은 macOS/Linux에서 `PORT=4000 npm start`, PowerShell에서 `$env:PORT=4000; npm start`로 설정합니다. 서버는 기본적으로 로컬 컴퓨터에서만 접근할 수 있도록 실행됩니다.

## 구현된 기능

- 모바일 반응형 홈, 데이트 조건 입력
- 성수/연남 가상 장소 기반 코스 추천: 선택 활동·두 명 총예산·이용 시간을 반영
- 코스 저장, 장소 추가·삭제·순서 변경, 이름·날짜 수정과 시간·예산 재계산
- 가상 장소 순서도 (실제 지도/교통 경로 아님)
- 데이트 완료 후 사진 한 장·소감·만족도 기록, 타임라인 검색·삭제
- 기념일 등록·삭제
- 브라우저 localStorage 저장과 저장 실패 안내

사용 흐름: 데이트 계획 → 추천 코스 저장 → 우리의 코스에서 편집 → 데이트 완료 → 추억 남기기.

## 현재 범위와 다음 단계

현재는 **한 브라우저에서 동작하는 로컬 데모**입니다. 로그인·커플 초대·두 기기 간 공유·DB·실제 지도/장소 API·자동 경로 기록·알림·관리자 기능은 구현하지 않았습니다. 기록 범위 선택은 메타데이터이며 실제 사용자별 접근 제어가 아닙니다. 실제 개인정보를 저장하는 서비스로 배포하기 전에는 인증과 서버/DB 권한 검증을 먼저 추가해야 합니다.

모든 장소 이름·좌표·가격은 가상 데이터이며, 이동은 구간당 15분 가정입니다. 브라우저 저장소 삭제 또는 다른 브라우저 사용 시 기록은 유지되지 않습니다. 사진은 JPEG/PNG/WebP 한 장, 최대 500KB이며 브라우저 저장 한도를 넘으면 저장이 취소됩니다.

설계 문서의 Next.js/TypeScript/Supabase는 후속 구현 제안입니다. 이번 실행 버전은 빠른 설치 없는 검증을 위해 Node.js 정적 서버 + ES Modules로 작성했습니다. 추천 도메인 로직과 UI를 분리하여 이후 프레임워크·실제 제공자로 전환할 수 있습니다.

## 파일 구성

- `server.mjs`: Node.js 정적 HTTP 서버
- `public/index.html`, `public/style.css`, `public/app.js`: 화면과 사용자 동작
- `public/domain.js`: 장소 데모 데이터, 추천·합계·저장소 복구 로직
- `tests/domain.test.mjs`: 추천·계산·텍스트 안전 처리·HTTP 테스트

## 실제 지도와 직접 코스 만들기

`우리의 코스 → 코스 추가하기` 또는 홈의 `코스 만들기`에서 날짜, 시작 시간, 지역, 예산, 이용 가능 시간을 입력합니다. 지도에서 장소 위치를 클릭한 뒤 이름, 주소, 활동, 두 명 비용, 체류 시간, 이전 장소에서의 이동 시간과 메모를 입력하고 `이 장소 추가`를 누릅니다. 방문 순서와 예상 종료 시간을 확인하고 `코스 저장하기`로 보관하세요. 편집 화면의 장소 추가·수정·삭제와 순서 변경은 마지막에 `코스 변경 저장`을 눌러야 저장됩니다.

- 실제 지도: Leaflet 1.9.4 + OpenStreetMap. 별도 API 키가 필요하지 않습니다. 지도 이미지는 인터넷 연결이 필요하며, 요청한 화면의 타일만 불러옵니다. 화면에 출처를 표시하고 브라우저의 HTTP 캐시를 사용합니다. [타일 이용 정책](https://operations.osmfoundation.org/policies/tiles/).
- 주소는 직접 입력하며 위치는 지도 클릭 또는 위도·경도 입력으로 정합니다. 주소 자동 검색과 실제 도보·대중교통 길찾기는 연결하지 않았습니다. 핀 연결선은 방문 순서만 나타냅니다.
- 이동 시간은 사용자가 입력하는 예상값입니다. 첫 장소의 이동 시간은 총시간에 포함하지 않습니다. 기본 이동 시간은 15분입니다.
- 데모 추천 장소는 가상 데이터라 실제 위치 핀을 표시하지 않습니다. 저장한 기존 코스도 계속 사용할 수 있습니다.
- 기록은 이 브라우저의 localStorage에 보관되며, 다른 브라우저와 자동 공유되지 않습니다.
- 서버 파일이 바뀌었으므로 기존 실행 창을 종료한 뒤 `run.bat`을 다시 실행하고 브라우저를 새로고침하세요.
## 네이버지도·사진·장소 활동 첨부

장소 추가 화면에서 네이버지도 `공유 → 링크 복사` 주소를 붙여넣을 수 있습니다. `naver.me`, `map.naver.com`, 네이버 플레이스 링크를 지원합니다. 링크만 첨부하는 경우 위도·경도를 입력하지 않아도 됩니다. 저장 후 코스 목록의 `장소·사진·링크 보기`를 펼치거나 코스 편집 화면에서 네이버지도 링크를 열 수 있습니다. 네이버지도 자체를 앱 안에 표시하는 API 연결은 하지 않았으며, 기존 지도 핀은 직접 좌표를 선택한 장소만 표시합니다.

장소별로 예약·메뉴·홈페이지 등 관련 링크와 링크 이름, `여기서 할 수 있는 것`을 줄마다 입력할 수 있습니다. 사진은 최대 3장, 한 장당 10MB 이하 JPG·PNG·WebP를 첨부할 수 있으며 긴 변 1000px 이하로 자동 축소하여 저장합니다. 사진을 눌러 크게 보거나 장소 수정에서 첨부 사진을 제거할 수 있습니다. 사진과 링크 변경 후 `장소 수정 반영 → 코스 변경 저장`을 누르세요. 코스 카드 표지에는 첨부한 첫 사진을 사용합니다. 링크에서 사진이나 영업 정보를 자동으로 가져오는 기능은 제공하지 않습니다.
## 화면 안에서 네이버 장소 검색하기

코스 만들기·편집 화면 상단의 검색창에 장소 이름이나 키워드를 입력하고 검색하세요. 결과의 `바로 추가`를 누르면 이름, 주소, 위치, 네이버지도 검색 링크와 제공되는 홈페이지·설명이 코스에 추가됩니다. 검색 결과의 비용과 체류 시간은 제공되지 않으므로 비용 0원·체류 60분은 기본값입니다. 추가 후 `수정`에서 비용·시간·사진·활동을 채우고 코스를 저장하세요. 같은 장소의 중복 추가는 막습니다.

실제 네이버 검색 신규 신청은 [네이버 클라우드 NAVER API HUB](https://guide.ncloud-docs.com/docs/apihub-application)에서 Application 등록 시 NAVER 검색 → 지역을 선택하고 프로젝트의 `.env` 파일에 아래 두 항목을 입력한 뒤 `run.bat`을 다시 실행합니다. NAVER API HUB의 **지역 검색** 인증정보입니다. `.env`의 `NAVER_SEARCH_PROVIDER=hub`는 새 API를 사용합니다. 기존 Developers 키가 있을 때만 `legacy`로 설정하세요.

```dotenv
NAVER_SEARCH_PROVIDER=hub
NAVER_CLIENT_ID=발급받은_Client_ID
NAVER_CLIENT_SECRET=발급받은_Client_Secret
```

키는 서버에서만 사용하고 화면이나 검색 응답으로 보내지 않습니다. `.env`는 Git에서 제외되어 있습니다. API가 연결되지 않았을 때는 `저장한 장소` 검색을 사용할 수 있습니다. 검색 호출은 검색 버튼을 누를 때만 발생하며 결과를 5분간 서버 메모리에 캐시합니다. 공식 지역 검색 API는 검색 한 번에 최대 5개 결과를 제공합니다. [공식 문서](https://developers.naver.com/docs/serviceapi/search/local/local.md).
## 가까운 곳끼리 추천 코스

`우리의 코스`에 첨부 목록을 바탕으로 만든 8개 코스를 제공합니다. 익선·종로, 북촌, 혜화·낙산(베이킹/드로잉 2개), 성수, 송리단길(나무반지/액세서리 2개), 홍대·연남으로 나눴습니다. `내 코스에 담기`로 오늘 날짜의 편집 가능한 코스로 복사하며, 방문 날짜·비용·예약 시간은 직접 조정합니다. 송리단길 액세서리 코스는 플라비 대신 체리시유를 선택할 수 있습니다.

현재 네이버 지역 검색 주소와 좌표로 확인했고 일부 지점의 주소는 첨부 이미지와 달라 최신 검색값을 사용했습니다. 각 구간의 직선거리를 기준으로 가까운 동선을 구성했습니다. 카드의 거리 합계는 직선거리이며 실제 도보 길찾기 결과가 아닙니다. 체류·이동 시간은 계획용 추정값이고 요금은 확인되지 않아 `비용 확인 필요`로 표시합니다. 사진의 영업 상태·휴무 정보는 특정 시점의 정보라 현재 상태로 취급하지 않습니다. 공방·전시 예약과 궁궐 운영일은 장소 링크에서 확인하세요.

원본 검색 자료: `data/curated-place-sources.json`. 코스 원본: `data/curated-courses.json`. `node scripts/build-curated-courses.mjs`로 확인된 자료에서 앱의 추천 코스 데이터를 다시 생성할 수 있습니다.
