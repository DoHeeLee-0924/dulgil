# 커플 맞춤형 데이트 코스 앱 — 유저플로우

## 1. 인증 및 커플 연결

```text
앱 최초 실행
→ 온보딩/시작 화면
→ 로그인 여부?
  ├─ 예 → 홈 대시보드 화면
  └─ 아니오 → 로그인 화면
      ├─ 회원가입 화면 → 가입 정보 제출 → 커플 연결 완료?
      ├─ 소셜 로그인 선택 → 커플 연결 완료?
      └─ 로그인 제출 → 커플 연결 완료?
          ├─ 예 → 홈 대시보드 화면
          └─ 아니오 → 커플 초대 화면 → 초대 코드 입력 → 초대 수락 확인 화면 → 초대 수락 버튼 탭 → 홈 대시보드 화면

초대 링크 터치 진입
→ 초대 수락 확인 화면
→ 초대 수락 버튼 탭
→ 홈 대시보드 화면
```

## 2. 홈 대시보드

```text
홈 대시보드 화면
├─ 다가오는 기념일 목록 → 기념일·일정 관리 화면
├─ 최근 데이트 기록 요약 → 추억 타임라인 화면
├─ 예정 데이트 코스 목록 → 코스 편집 화면
├─ 취향·조건 설정 화면
├─ 기념일·일정 관리 화면
└─ 프로필·설정 화면
```

## 3. 코스 추천

```text
취향·조건 설정 화면
├─ 지역·날짜·시간 입력 ─┐
├─ 예산 범위 설정 ───────┼→ 코스 추천 요청 → 추천 코스 목록 화면
├─ 선호 활동 선택 ───────┤                         → 추천 코스 카드 목록
└─ 개별 선호 조건 비교 ───┘                         → 추천 코스 선택
                                                      → 추천 코스 상세 화면
                                                          → 코스 장소·경로·비용 정보
                                                              ├─ 다시 추천받기 버튼 탭 → 추천 코스 목록 화면
                                                              └─ 코스 저장 버튼 탭 → 코스 편집 화면

기념일·일정 관리 화면
→ 기념일 코스 추천 요청
→ 추천 코스 목록 화면
```

## 4. 코스 편집 및 지도

```text
코스 편집 화면
├─ 장소 검색·추가 → 장소 검색 화면 → 장소 검색 결과 → 장소 선택 → 코스 편집 화면
├─ 장소 삭제·교체 → 코스 편집 화면
├─ 방문 순서 변경 → 코스 편집 화면
├─ 수정된 시간·예산 계산
├─ 코스 지도 경로 화면
└─ 코스 저장·공유 버튼 탭 → 코스 저장 확정 화면 → 데이트 기록 작성 화면
```

## 5. 데이트 기록 및 추억 타임라인

```text
데이트 기록 작성 화면
├─ 사진 업로드 → 사진 업로드 성공?
│   ├─ 예 → 데이트 기록 작성 화면
│   └─ 아니오 → 사진 업로드 오류 안내 → 데이트 기록 작성 화면
├─ 텍스트 메모 입력
├─ 만족도·장소별 후기 입력
└─ 공개 범위 설정 → 기록 저장 제출 → 추억 타임라인 화면

추억 타임라인 화면
→ 날짜순 기록 목록
   ├─ 기록 검색 필터 적용
   └─ 기록 카드 선택 → 데이트 기록 상세 화면 → 사진·메모·경로 기록
```

## 6. 기념일 및 일정 관리

```text
기념일·일정 관리 화면
├─ 기념일·예정 일정 목록 → 기념일 추가·수정·삭제
├─ 알림 설정
└─ 기념일 코스 추천 요청 → 추천 코스 목록 화면
```

## 7. 프로필·설정 및 권한

```text
프로필·설정 화면
├─ 커플 공간 관리 화면 → 커플 연결 해제 → 연결 해제 확인?
│   ├─ 예 → 커플 초대 화면
│   └─ 아니오 → 홈 대시보드 화면
└─ 개인정보·권한 설정 화면
    ├─ 위치 권한 허용·거부
    └─ 계정·기록 삭제 요청 → 계정 삭제 확인 화면 → 삭제 최종 확인 제출 → 온보딩/시작 화면
```

## 8. 관리자

```text
관리자 대시보드
→ 신고 장소·기록 목록
→ 신고 항목 검토·조치
```
