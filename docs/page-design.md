# 둘길 페이지 디자인

2026-10-15 · PRD / 기능명세서 / 유저플로우 기반

## 시각 방향

‘둘이 만드는 하루’를 주제로, 아이보리 배경과 숲색 주요 버튼, 세이지 그린과 살구색 포인트를 사용한다. 넓은 여백, 둥근 카드, 작은 영문 구분 문구, 자연을 소재로 한 CSS 일러스트를 공통 언어로 사용한다. 데스크톱은 좌측 사이드바, 모바일은 하단 5개 탭으로 이동한다. 모션 감소 설정과 키보드 포커스, 레이블, 건너뛰기 링크를 제공한다.

## 화면 및 사용자 흐름

현재 앱은 hash 경로를 사용한다. 주소의 `#` 뒤 경로로 바로 이동할 수 있다.

| 화면 | 경로 | 디자인과 역할 |
|---|---|---|
| 온보딩 | #onboarding | 브랜드 소개, 엽서 일러스트, 시작/둘러보기 |
| 로그인 | #login | 브랜드 소개와 프로필 진입 폼, 소셜 로그인 준비 상태 |
| 회원가입 | #signup | 닉네임 기반 데모 프로필 생성 |
| 커플 초대 | #couple | 초대 코드 카드, 코드 입력, 연결 상태 |
| 초대 수락 | #accept | 두 아바타와 상대 닉네임, 수락 버튼 |
| 홈 | #home | 오늘의 헤더, 데이트 CTA, 지표, 예정 코스, 기록, 기념일 |
| 취향 | #preferences | 활동 칩, 분위기 선택, 이동 수단, 회피 메모 |
| 조건 입력 | #plan | 단계 표시, 지역/날짜/시간/예산/활동, 설명 카드 |
| 추천 목록 | #recommendations | 조건 요약과 추천 코스 카드 |

로그인·초대는 실제 인증 없이 닉네임과 연결 표시만 이 브라우저에 저장하는 화면 데모다. 이메일·비밀번호를 수집하지 않는다. 관리자 메뉴도 실제 권한이 아닌 샘플 화면이다. 실제 인증 화면과 혼동하지 않도록 안내를 표시한다.

추천 → 상세 → 저장 확인 → 코스 상세 → 편집/장소 검색/지도 → 완료 확인 → 기록 작성 → 기록 상세 → 보관함을 연결했다. 새로고침 시 코스·기록의 id 경로는 유지되며 추천 결과는 일시 데이터이므로 재입력을 안내한다. 데이터가 없거나 삭제되었을 때는 빈 화면과 돌아가기 버튼을 제공한다. 기존 v1 코스·기록·기념일을 유지하며 새 프로필·설정 필드에 기본값을 부여한다.

## 구현 수준

실제 동작: 조건 기반 가상 코스 추천, 코스 편집·삭제, 사진/텍스트 기록과 검색·삭제, 기념일 등록·수정·삭제, 달력, 프로필/취향 로컬 저장, 샘플 관리자 상태 변경.

데모만 제공: 계정 인증, 커플 연결, 기록 범위, 알림 설정, 실제 지도·경로, 신고 조치. 소셜 로그인과 실제 알림 발송 버튼은 비활성화했다. 자동 실제 경로·장소별 후기·거리 계산은 아직 제공하지 않는다. 비용은 두 명 총액, 이동은 구간당 15분으로 가정한다.

## 실행

`npm start` 후 http://localhost:3000/#pages 에서 모든 페이지를 살펴본다. 별도 패키지 설치나 API 키는 필요하지 않다. Windows에서도 직접 실행되도록 Node.js 시작 파일의 경로 비교를 수정했다.

## 검증

- `npm test`: 추천 조건·합계·HTML escape·HTTP 서버·직접 실행 등 6개 테스트 통과.
- DOM 시나리오: 20개 기본 경로와 데이터 상세 화면, 코스 재정렬, 추억 저장, 기념일 수정, 닉네임 저장, 연결 해제 취소/확인 검증.
- Chromium: 실제 클릭으로 추천→저장→편집→장소 추가→완료→기록→새로고침 재열람 확인.
- 390px 모바일에서 17개 주요 경로의 가로 넘침 없음, 브라우저 JS/CSP 오류 없음 확인.
- Windows 시작 문제는 플랫폼 독립 경로 비교로 수정하고 직접 실행 테스트를 추가했다. Windows OS 자체에서의 재실행은 사용자 PC에서 확인해야 한다.
