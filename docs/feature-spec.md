## 1. 회원가입 및 커플 연결
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

사용자가 계정을 생성하고 연인을 초대하거나 초대 코드를 입력해 하나의 커플 공간을 구성할 수 있어야 한다. 각 사용자는 공유 기록의 열람 및 편집 범위를 확인하고 관리할 수 있어야 한다.

**수용 기준:**
```
1. ✓ 사용자는 이메일, 소셜 로그인 등 지원되는 방식으로 계정을 생성하고 로그인할 수 있다.
2. ✓ 사용자는 초대 링크 또는 초대 코드를 통해 연인을 커플 공간에 초대할 수 있다.
3. ✓ 초대받은 사용자가 수락하면 두 사용자가 동일한 커플 공간의 구성원으로 표시된다.
4. ✓ 커플 연결 전에는 개인 정보와 개인 기록이 상대방에게 노출되지 않는다.
5. ✓ 사용자는 커플 연결 해제와 공유 기록의 처리 방식을 확인하고 실행할 수 있다.
```


---


## 2. 커플 취향 및 데이트 조건 설정
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

커플이 지역, 날짜, 이용 가능 시간, 예산, 이동 수단, 선호 활동, 분위기와 음식 취향을 입력하고 두 사람의 개별 선호를 함께 관리할 수 있어야 한다.

**수용 기준:**
```
1. ✓ 사용자는 데이트 지역과 날짜, 시작·종료 예정 시간을 입력할 수 있다.
2. ✓ 사용자는 총예산 또는 장소별 예산 범위를 설정할 수 있다.
3. ✓ 사용자는 식사, 카페, 문화생활, 야외활동 등 선호 활동과 피하고 싶은 활동을 선택할 수 있다.
4. ✓ 두 사용자의 선호 조건과 공통 선호 조건을 구분하여 확인할 수 있다.
5. ✓ 저장된 조건은 이후 데이트 코스 추천 요청 시 자동으로 불러올 수 있다.
```


---


## 3. 맞춤형 데이트 코스 추천
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

사용자가 입력한 취향과 일정 조건을 기반으로 여러 장소가 연결된 큐레이션 코스를 제공하고, 코스별 예상 소요 시간·이동 거리·예상 비용·추천 이유를 보여줘야 한다.

**수용 기준:**
```
1. ✓ 사용자는 최소 하나 이상의 지역, 시간 또는 활동 조건을 입력해 코스 추천을 요청할 수 있다.
2. ✓ 추천 결과에는 코스명, 포함 장소, 장소별 체류 예상 시간, 이동 순서가 표시된다.
3. ✓ 각 코스에는 예상 총 소요 시간, 예상 이동 거리와 예산 정보가 표시된다.
4. ✓ 추천 결과는 커플의 공통 취향과 개별 선호를 반영한 추천 이유를 제공한다.
5. ✓ 사용자는 추천 코스를 저장하거나 다시 추천받을 수 있다.
6. ✓ 운영 중인 장소가 폐업 또는 이용 불가 상태로 확인되면 해당 장소를 추천 결과에서 제외하거나 대체 장소를 제안한다.
```


---


## 4. 데이트 코스 직접 구성 및 지도 경로
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

사용자가 추천 코스를 기반으로 장소를 추가·삭제·교체하고 방문 순서를 변경할 수 있도록 하며, 지도에서 전체 이동 경로와 장소 정보를 확인할 수 있어야 한다.

**수용 기준:**
```
1. ✓ 사용자는 장소 검색을 통해 기존 코스에 장소를 추가할 수 있다.
2. ✓ 사용자는 코스에서 장소를 삭제하거나 다른 장소로 교체할 수 있다.
3. ✓ 사용자는 장소의 방문 순서를 변경할 수 있다.
4. ✓ 지도에서 코스에 포함된 장소와 장소 간 이동 경로를 확인할 수 있다.
5. ✓ 코스 수정 시 예상 총 시간과 예산이 자동으로 다시 계산된다.
6. ✓ 사용자는 완성한 코스를 제목, 날짜, 메모와 함께 저장하고 연인과 공유할 수 있다.
```


---


## 5. 데이트 기록 및 추억 타임라인
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

완료한 데이트에 사진과 글, 방문 장소, 이동 경로, 만족도와 후기를 기록하고 날짜순 타임라인과 기념일 기록으로 다시 볼 수 있어야 한다.

**수용 기준:**
```
1. ✓ 사용자는 저장된 데이트 코스에서 데이트 기록을 생성할 수 있다.
2. ✓ 사용자는 사진, 텍스트 메모, 방문 장소와 실제 이동 경로를 기록할 수 있다.
3. ✓ 사용자는 데이트 전체 만족도와 장소별 후기를 입력할 수 있다.
4. ✓ 기록은 데이트 날짜순 타임라인으로 표시되고 장소·지역·태그로 검색할 수 있다.
5. ✓ 사용자는 기록의 공개 범위를 커플 전용 또는 개인 전용으로 설정할 수 있다.
6. ✓ 사진 업로드 실패, 지원하지 않는 파일 형식과 용량 초과 상황에 대해 이해하기 쉬운 안내를 제공한다.
```


---


## 6. 기념일 및 일정 관리
> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

커플의 만남 시작일, 생일, 기념일과 예정된 데이트를 등록하고 타임라인에서 과거 기록과 다가오는 일정을 함께 확인할 수 있어야 한다.

**수용 기준:**
```
1. ✓ 사용자는 기념일 이름과 날짜를 등록, 수정, 삭제할 수 있다.
2. ✓ 다가오는 기념일과 예정된 데이트가 날짜순으로 표시된다.
3. ✓ 사용자는 특정 기념일에 맞는 데이트 코스 추천을 요청할 수 있다.
4. ✓ 사용자는 선택한 기념일에 대한 알림 여부와 알림 시점을 설정할 수 있다.
5. ✓ 기념일과 데이트 기록은 커플 공간 구성원에게만 표시된다.
```


---


## 7. 개인정보 및 공유 권한 관리
> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

위치 정보, 사진, 연애 기록과 같은 민감한 정보를 안전하게 관리하고 사용자가 기록별 공유 범위와 계정 보안 설정을 직접 제어할 수 있어야 한다.

**수용 기준:**
```
1. ✓ 사용자는 위치 권한 요청의 허용 또는 거부를 선택할 수 있으며, 거부 시에도 직접 지역을 입력해 주요 기능을 이용할 수 있다.
2. ✓ 사용자는 기록별로 커플 공유 또는 개인 전용 여부를 설정할 수 있다.
3. ✓ 다른 사용자가 커플 공간에 접근하거나 기록을 공유할 때 동의 상태를 확인할 수 있다.
4. ✓ 사용자는 자신의 계정과 기록을 삭제할 수 있으며 삭제 대상과 처리 결과를 안내받는다.
5. ✓ 비밀번호, 소셜 로그인 토큰과 같은 인증 정보는 안전하게 처리되고, 관리자도 원문을 확인할 수 없다.
6. ✓ 관리자는 신고된 장소 정보나 부적절한 기록을 검토하고 필요한 조치를 수행할 수 있다.
```
